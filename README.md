## 🔍 Project Overview

**Nautical Armor** is a specialized B2B manufacturing website built for a company that produces sacrificial anodes for the marine industry. This project showcases my ability to create a sophisticated, trust-building online presence for an industrial client.

> *"From complex technical specifications to global shipping documentation - a complete digital ecosystem for a manufacturing business"*

### Client Requirements

| Requirement | Solution |
|-------------|----------|
| 📊 **Product Catalog** | Custom post type architecture with technical specifications |
| 📚 **Educational Content** | Blog system with in-depth technical articles |
| 🔍 **Trust Building** | Behind-the-scenes content (production, QC, shipping) |
| 🌍 **Global Reach** | Multi-region content strategy (USA, Europe, Scandinavia) |
| 📱 **Professional Design** | Custom Elementor layouts with industrial aesthetic |
| 📄 **Technical Docs** | Integrated PDF catalogs and specification diagrams |

## 📥 Installation / Import

If you'd like to import this content into your own WordPress installation:

### Prerequisites

- ✅ WordPress 5.0 or higher
- ✅ Elementor (free version) - Pro version recommended for full compatibility
- ✅ PHP 7.4 or higher
- ✅ MySQL 5.6 or higher

### Step-by-Step Import

1. **Download** the `nauticalarmor.WordPress.2026-02-16.xml` file from this repository

2. In your WordPress admin, go to **Tools → Import**

3. Install and activate the **WordPress Importer** plugin

4. Click **Run Importer**

5. Upload the downloaded `.xml` file

6. **Assign posts** to an existing or new author

7. **IMPORTANT:** Check **"Download and import file attachments"** - this will import all 219 images!

8. Click **Submit** and wait for the import to complete

9. **Post-Import Steps:**
    - Install and activate Elementor (Pro recommended)
    - Configure your permalinks (Settings → Permalinks → Post name)
    - Update the navigation menus if needed
    - Set your homepage in Settings → Reading

### ⏱️ Import Time

- **Small server:** 5-10 minutes
- **Good hosting:** 2-3 minutes
- **Local environment:** 1-2 minutes
